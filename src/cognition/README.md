# Cognition Layer

Cognition is internal infrastructure for observation, latent modeling,
continuity inference, and salience estimation.

Latent outputs remain internal-only and must be transformed before surfacing.
Glossary candidate extraction remains descriptive continuity scaffolding, not symbolic interpretation.
Latent cognition may suggest possibilities but may not directly mutate canonical reflective domains.
Opening generation is a bounded transformation layer: user-gated, suppressible, and non-authoritative.
