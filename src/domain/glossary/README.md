# Glossary Domain

Glossary memory is autobiographical continuity memory.

It preserves recurring motifs as user-steerable memory anchors.
It does not provide universal symbolic meaning.
It does not infer hidden truth.

Glossary contextualizes continuity and remains revisable.
Candidate lifecycle states are explicit: `candidate`, `pinned`, `suppressed`, `ignored`.
Suppression reduces resurfacing pressure and preserves reflective pacing.
