# Openings Domain

Openings are optional reflective invitations.

This domain preserves:
- user-gated activation
- suppression and silence legitimacy
- cadence-aware dedupe and repetition dampening
- suppression lifecycle (temporary, indefinite, user-reactivated)
- non-authoritative reflective utterance language
- explicit provenance from latent/canonical sources

Openings are not:
- recommendations
- workflow prompts
- authoritative interpretations
