# Reflective Objects Domain

## Legacy Backend V1 Quarantine

This folder remains in the repo only as a protected compatibility dependency for existing pages, routes, and UI.

It must not be used as the Backend V2 root.

Backend V2 is clean-room and domain-first. The generic `reflective_object` substrate is legacy/disposable backend scaffolding and is not active authority for new Backend V2 work.

If a protected surface still imports this domain, keep the surface and record the dependency. Do not extend this substrate for new backend implementation.
