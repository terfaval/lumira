# Observation Domain

Observation is descriptive orientation only.

It answers:
- what appears
- what changes
- what is directly evidenced

It does not answer:
- what it ultimately means
- symbolic certainty
- psychological diagnosis

Boundary hardening invariants:
- semantic policy gate runs at ingress (`accept`, `accept_with_uncertainty`, `reject_interpretive`, `defer_insufficient_evidence`)
- latent/opening phrasing markers are rejected from durable Observation writes
- recurrence candidates must remain descriptive continuity hints with evidence-aware handling

Current B-level slice dimensions (first-class additions):
- `agency_state`
- `metacognitive_moment`
- `affect_transition`
- `emotional_contradiction`
- `affective_atmosphere`
- `spatial_instability`
- `dream_state_quality`
- `continuity_fragment`
- `altered_realism`
