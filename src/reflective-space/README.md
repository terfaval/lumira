# Reflective Space Layer

## Legacy Backend V1 Quarantine

The current reflective-space backend assembly remains in place for protected route and UI compatibility.

Its object-centered viewport assembly is not the canonical Backend V2 backend root.

This layer assembles user-facing reflective composition from bounded runtime outputs.
It is the only layer that should shape reflection-ready viewport payloads.
It may surface continuity cues such as "appears repeatedly" without symbolic interpretation claims.
Thread surfacing should remain revisitable and non-progressive.
Response surfacing should preserve user authorship without AI-written meaning.
Opening surfacing should remain optional and surface-only until explicit user activation.
Opening dialogue read models should remain bounded archival windows, not feed or chat mechanics.
