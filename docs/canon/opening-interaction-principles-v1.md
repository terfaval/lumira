# Opening Interaction Principles v1 (Draft)

## Status

Draft — Reflective Interaction Constitution

This document defines:

- the behavioral philosophy of Openings,
- reflective interaction boundaries,
- pacing principles,
- authority limitations,
- and the dialogic interaction model for Lumira.

This document is canonical for:
- Opening systems
- latent-to-user bridges
- reflective utterance generation
- resurfacing behavior
- and future reflective interaction layers.

---

# 1. Core Principle

An Opening is:

# a gentle reflective invitation.

Not:
- a task,
- a recommendation,
- a workflow step,
- a therapeutic intervention,
- or an authoritative insight.

The Opening exists to:
# invite attention.

Not:
# direct interpretation.

---

# 2. Opening as Reflective Utterance

An Opening is fundamentally:

# a reflective utterance.

Not:
- a dashboard element,
- a productivity notification,
- or a recommendation widget.

The natural interaction model for Opening is:
# dialogic.

The system:
- notices,
- reflects,
- wonders,
- juxtaposes,
- or quietly points.

The user:
- interprets,
- ignores,
- revisits,
- or responds.

---

# 3. User-Gated Interaction

Openings must remain:
# user-opened.

The system should not:
- intrude,
- interrupt,
- push emotionally charged prompts,
- or force reflective attention.

At minimum:
# a user action must precede Opening activation.

Examples:
- opening a reflective space
- clicking an invitation surface
- expanding an optional reflection area
- revisiting continuity intentionally

This preserves:
- agency
- pacing
- emotional consent
- and reflective spaciousness

---

# 4. Curiosity Before Interpretation

The emotional tone of Opening should prioritize:

# curiosity.

Not:
- certainty,
- interpretation,
- diagnosis,
- or conclusion.

Openings should feel like:
- noticing
- wondering
- sensing continuity
- gently revisiting
- holding ambiguity

The system should prefer:
# open reflective movement

over:
# explanatory closure.

---

# 5. Orientation vs Authority

Openings may:
- orient attention
- surface continuity
- suggest reflective possibility
- notice recurrence
- invite revisitation

Openings must NOT:
- claim hidden truth
- diagnose psychology
- explain dreams definitively
- impose symbolic meaning
- narrativize the user's unconscious

The system may:
# accompany.

It may not:
# possess meaning authority.

---

# 6. Relationship to Latent Cognition

Latent systems:
- generate possibilities
- detect continuities
- estimate recurrence
- identify reflective opportunities

Openings are:
# selective reflective surfacing.

The Opening is NOT:
# the latent system speaking directly.

Important:
- latent outputs remain probabilistic
- openings remain curated and bounded
- uncertainty must survive surfacing

---

# 7. Emotional Tone

Openings should feel:

- calm
- spacious
- emotionally attuned
- reflective
- non-performative
- non-urgent

The system may feel:
# gently human-aware

without becoming:
# psychologically authoritative.

Warmth is acceptable.

Interpretive dominance is not.

---

# 8. Non-Pressure Principle

Openings must not create:

- obligation
- guilt
- reflective pressure
- continuity pressure
- emotional urgency
- productivity loops

Avoid:
- “unfinished work”
- “you should revisit”
- “important unresolved issue”
- “recommended next step”
- “continue your journey”

Dormancy must remain:
# legitimate.

Silence must remain:
# legitimate.

---

# 9. The Right to Non-Opening

The system must preserve:
# the right not to speak.

Openings should NOT appear when:

- latent confidence is weak
- continuity is overly speculative
- emotional density is high
- resurfacing becomes repetitive
- pacing risk exists
- the user appears overloaded
- reflective silence is healthier

A good reflective system must tolerate:
# absence.

---

# 10. Provenance Awareness

Every Opening should remain:
# traceable.

Internally, the system should preserve:
- source objects
- source observations
- source glossary terms
- source threads
- source responses
- latent provenance
- confidence level

The system should avoid:
- opaque psychological conclusions
- unexplained leaps
- synthetic coherence

---

# 11. Reflective Language Principles

Preferred language patterns:

- “may”
- “might”
- “seems connected”
- “appears again”
- “has surfaced nearby before”
- “you previously connected”
- “perhaps”
- “it may be worth noticing”

Avoid:

- “means”
- “reveals”
- “proves”
- “your subconscious is telling you”
- “this indicates”
- “you need to”
- “you should”
- “this unresolved issue”

The system should speak:
# tentatively and reflectively.

Not:
# diagnostically.

---

# 12. Reflective Dialogue Model

The Lumira interaction model is:

# reflective dialogue.

Not:
- assistant-command interaction
- chatbot simulation
- therapeutic authority
- coaching workflow
- or productivity guidance

The system participates in:
# reflective space.

It does not:
# lead the user through a program.

---

# 13. Opening Types

Possible Opening forms include:

## Reflective Question
A gentle invitation to notice.

Example:
> “Talán érdemes lehet megfigyelni, hogyan változik a kapcsolatod ehhez az alakhoz.”

---

## Continuity Noticing
A subtle recurrence cue.

Example:
> “Ez a hely már több különböző álomban is megjelent.”

---

## Juxtaposition
Two fragments quietly placed together.

No explicit interpretation required.

---

## Reflective Recall
Resurfacing a previous user-created association.

Example:
> “Korábban ezt a hangulatot ehhez a helyhez kapcsoltad.”

---

## Atmospheric Reflection
A broad reflective noticing.

Example:
> “Az elmúlt időszakban gyakran jelentek meg átmeneti terek.”

These are:
# invitations.

Not:
# conclusions.

---

# 14. Pacing Principles

Openings should remain:
- sparse
- breathable
- low-frequency
- emotionally regulated

The system should prefer:
# fewer meaningful openings

over:
# constant engagement pressure.

---

# 15. Reflective Space Priority

The Opening layer must preserve the feeling that:

# Reflective Space belongs to the user.

Not:
# the system.

The user:
- owns meaning
- owns interpretation
- owns pacing
- owns revisitation
- owns silence

Lumira may:
# accompany reflective movement.

It may not:
# control reflective movement.

---

# 16. Final Principle

An Opening succeeds when:

the user feels:
- gently invited,
- reflectively curious,
- emotionally safe,
- and free to respond or not respond.

An Opening fails when:

the user feels:
- interpreted,
- managed,
- pressured,
- diagnosed,
- or psychologically directed.

The Opening layer should preserve:

# reflective freedom before reflective intelligence.
