## 1) Latent Weighting Philosophy v1

## 1.1 Purpose

Weighting answers:

# what may deserve attention now

It does not answer:

# what the dream ultimately means

## 1.2 Signal classes

1. Primary grounded signals:
   - object-local observations
   - object-local highlights
   - object-local user responses
2. Secondary continuity signals:
   - thread continuity overlap
   - glossary motif overlap
   - validated cross-object recurrence
3. User validation signals:
   - explicit confirmation/rejection
   - revisitation behavior
   - suppression/defer behavior
4. Anti-signals:
   - weak evidence
   - unresolved extraction uncertainty
   - repeated ignored resurfacing
   - suppression history

## 1.3 Evidence quality policy

- Strong evidence:
  - explicit span-grounded or high-context multi-fragment support.
- Medium evidence:
  - snippet-only support with coherent local context.
- Weak evidence:
  - fallback/low-anchor fragments or low trace coherence.

Rules:
- Weak evidence may propose but cannot foreground by itself.
- Medium evidence requires user or continuity corroboration for foreground.
- Strong evidence still remains probabilistic unless user-validated.

## 1.4 Provenance policy

- `manual_user` and `reviewed` may receive higher trust than pure extractor-derived signals.
- `system_extract` remains constrained by uncertainty penalties.
- `imported_transform` requires explicit coherence checks before promotion.

## 1.5 Uncertainty policy

- Semantic uncertainty, coherence risk, and weak trace depth apply penalties.
- Penalties stack faster than boosts for non-user signals.
- Recurrence count never neutralizes uncertainty penalties alone.

## 1.6 User salience precedence

- User-authored salience anchors (highlights, notes, sustained writing, explicit resonance) outrank latent-only recurrence.
- Latent may nominate attention; user interaction stabilizes attention.

## 1.7 Suppression/defer policy

- Suppression/defer are negative weighting events for resurfacing eligibility.
- Suppression should gate visibility first, then decrease candidate salience for a refractory window.

Deliverable:

# Latent Weighting Philosophy v1 is a weighted, uncertainty-penalized, user-prioritized attentional model.

## 2) Reflective Center Selection Model v1

## 2.1 Center definition

A center is:

# best current candidate for sustained reflective attention

not truth, not verdict, not final interpretation.

## 2.2 Candidate pool

- Start with object-local candidates.
- Add only overlap-qualified continuity neighbors.
- Exclude suppressed or recently rejected candidates unless explicitly user-reactivated.

## 2.3 Eligibility gates

A center candidate must pass all:
1. Minimum evidence gate.
2. Uncertainty tolerance gate.
3. Pressure/suppression gate.
4. Scope legitimacy gate.

## 2.4 Selection logic

- Select highest eligible center score.
- Enforce one active foreground center in Deep Reflection.
- If no candidate clears threshold, select no center.

## 2.5 Stabilization and anti-thrashing

- Use center stickiness:
  - active center requires materially stronger challenger to be replaced.
- Use hysteresis:
  - promote threshold > retain threshold.
- Use cooldown:
  - repeated switching is blocked unless user pull is explicit.

## 2.6 Center weakening factors

- user rejection/suppression
- repeated non-engagement
- unresolved weak-evidence persistence
- contradiction by stronger recent user signals

Deliverable:

# Reflective Center Selection Model v1 is single-center, threshold-gated, and anti-thrashing.

## 3) User Validation and Meaning Stabilization Model v1

## 3.1 Core rule

Latent must not self-validate.

Meaning stabilizes only through evidence + user interaction.

## 3.2 Validation signals

Positive:
- explicit resonance confirmation
- elaborative response writing
- revisitation of same center/motif
- glossary note/pin linking
- stable highlight clustering around same continuity line

Negative:
- explicit rejection
- suppression/defer
- repeated ignore under low-pressure resurfacing
- contradiction in subsequent user narratives

## 3.3 Persistence and decay

- Validation influence persists but decays over time without reinforcement.
- Decay is slower for explicit user-authored notes than passive behavior signals.

## 3.4 Contradictory-signal handling

- conflicting signals do not collapse to certainty;
- they produce ambivalent state and center-strength damping.

## 3.5 Stabilization levels

- `possible` -> `emerging` -> `user_resonant` -> `stabilized`
- demotions:
  - `stabilized` -> `weakened` -> `dormant/silent`

Deliverable:

# User Validation and Meaning Stabilization Model v1 makes user interaction the primary stabilizer of latent confidence.

## 5) Reflective Attention Layering Model v1

Layers:

1. Foreground:
   - one active center, engage-now eligible.
2. Midground:
   - related, helpful, non-demanding neighborhood.
3. Background:
   - dormant, weak, historical, or not currently relevant continuity.
4. Silent:
   - intentionally withheld due to uncertainty, suppression, or pacing risk.

## Promotion rules

- requires evidence sufficiency plus local relevance.
- cross-layer upward promotion requires stronger proof than retention.
- user pull can accelerate promotion.

## Demotion rules

- suppression/defer
- unresolved weak evidence
- repeated non-engagement
- overload pressure

## Time-in-foreground rule

- no permanent foreground without ongoing user or evidence support.
- foreground should naturally decay to midground if not reinforced.

## Constraint

# demotion-before-expansion is mandatory.

Deliverable:

# Reflective Attention Layering Model v1 preserves calm continuity through explicit promotion/demotion contracts.

## 6) Anti-Amplification Governance Model v1

## 6.1 Amplification risks addressed

- recursive reinforcement
- lexical repetition inflation
- synthetic continuity growth
- pseudo-mythology formation
- latent self-confirmation loops

## 6.2 Governance controls

1. Recurrence refractory window:
   - repeated near-identical motifs cannot gain weight in short windows.
2. Weak-signal decay:
   - weak continuity scores decay aggressively if not user-validated.
3. Repetition cap:
   - recurrence increments saturate unless evidence diversity grows.
4. Resurfacing throttle:
   - repeated unengaged resurfacing lowers future resurfacing eligibility.
5. Cross-snapshot dedupe:
   - same object + same motif + same phrasing should not repeatedly escalate.
6. Suppression supremacy:
   - suppression overrides inferred importance during policy windows.

Deliverable:

# Anti-Amplification Governance Model v1 prioritizes decay, refractory behavior, and suppression over recursive inference growth.
